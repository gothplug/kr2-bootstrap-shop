# kr2-bootstrap-shop — учебный интернет-магазин TechNest

Сайт интернет-магазина гаджетов, сверстанный на Bootstrap 5.
Выполнен в рамках дисциплины «Фронтенд и бэкенд разработка».

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

TechNest — каталог из 9 гаджетов в 4 категориях (аудио, носимые устройства, периферия, аксессуары).
Пользователь может:

- посмотреть каталог, отфильтровать товары по категории и цене, найти товар по названию и отсортировать список;
- открыть страницу товара с характеристиками, комплектацией и условиями доставки;
- добавить товары в корзину или оформить быстрый заказ в модальном окне;
- оформить полную заявку на странице `order.html` с расчётом стоимости доставки.

Предметная область та же, что в КР №1 (интернет-магазин), но реализация новая: вся вёрстка построена
на сетке и компонентах Bootstrap, а собственный CSS только дополняет их.

## Используемый фреймворк

Bootstrap 5.3.8 (CSS и JS Bundle с Popper).

## Способ подключения Bootstrap

Bootstrap подключён **локально**, без CDN. Скомпилированные файлы фреймворка лежат в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css` — стили;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JS Bundle (нужен для navbar, modal, offcanvas, accordion, tabs, carousel, toast, tooltip, dropdown).

Порядок подключения на каждой странице:

```html
<!-- в <head>: сначала Bootstrap, потом собственные стили -->
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">

<!-- перед </body>: сначала Bootstrap JS Bundle, потом скрипты проекта -->
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/data.js"></script>
<script src="js/main.js"></script>
```

`custom.css` подключается после Bootstrap, чтобы его правила могли уточнять стандартные стили.

## Bootstrap-сетка

| Класс | Где используется |
|---|---|
| `container` | основа всех страниц: шапка, разделы, подвал |
| `row` + `g-*` | все сетки; отступы между колонками заданы только через `g-2`, `g-3`, `g-4`, `g-5` |
| `col-12` | на телефоне любой блок занимает всю ширину |
| `col-sm-6` | карточки товаров: 2 в ряд от 576 px |
| `col-md-*` | поля формы заявки (`col-md-6`, `col-md-8`, `col-md-4`), карточки контактов (`col-md-4`) |
| `col-lg-*` | hero (`col-lg-6` + `col-lg-6`), каталог (`col-lg-3` фильтры + `col-lg-9` товары), заявка (`col-lg-8` + `col-lg-4`), популярные товары (`col-lg-3`) |
| `col-xl-4` | 3 карточки в ряд в каталоге на широком экране |

Как перестраиваются карточки в каталоге: 1 колонка на телефоне → 2 колонки от 576 px → 3 колонки от 1200 px.

## Реализованные Bootstrap-компоненты

Обязательные:

- `navbar` — на всех страницах, с мобильным меню (`navbar-toggler` + `collapse`), выпадающим списком категорий (`dropdown`) и поиском;
- `card` — карточки товаров, преимуществ, категорий, отзывов, контактов, блок «Ваш заказ»;
- `btn` — варианты `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-success`, `btn-info`, `btn-light`, `btn-outline-danger`, размеры `btn-lg`/`btn-sm`, `btn-check` для выбора доставки;
- `badge` — «Хит», «Новинка», «Скидка», процент скидки, наличие товара, счётчик корзины, количество товаров в категории;
- `alert` — сообщения об успешной отправке и об ошибках формы, подсказки о доставке и возврате, «Ничего не найдено» в каталоге;
- `modal` — быстрый заказ из карточки товара (название, цена и картинка товара подставляются автоматически);
- `form-control` — все текстовые поля, e-mail, телефон, дата, комментарий;
- `form-select` — товар или тема заявки, количество в быстром заказе, сортировка каталога, тема обращения;
- `input-group` — телефон с префиксом `+7`, e-mail с `@`, количество с кнопками `−`/`+`, цена «от/до», поиск;
- `form-check` — согласие на обработку данных, категории в фильтрах; `form-switch` — фильтры и подписка.

Дополнительные:

- `accordion` — блок «Частые вопросы» на главной;
- `carousel` — специальные предложения в hero-блоке;
- `nav-tabs` (tabs) — описание, характеристики, комплектация и доставка на странице товара;
- `offcanvas` — корзина на всех страницах и панель фильтров каталога на телефоне (`offcanvas-lg`);
- `toast` — уведомления «Товар добавлен в корзину», «Заявка отправлена»;
- `pagination` — постраничный вывод каталога (по 6 товаров);
- `breadcrumb` — хлебные крошки на внутренних страницах;
- `list-group`, `table` (`table-striped`, `table-hover`, `table-responsive`), `spinner`, `tooltip`, `dropdown`.

## Форма заявки (`order.html`)

Поля: имя, e-mail, телефон, удобная дата связи, товар или тема заявки, количество, способ получения, адрес,
комментарий, согласие на обработку данных, подписка на новости и кнопка отправки.

- у всех полей есть `label` и `name`, обязательные поля помечены `required` и звёздочкой;
- проверка в стиле Bootstrap: `novalidate` + класс `was-validated` и подсказки `invalid-feedback`;
- телефон проверяется атрибутом `pattern`, а маска `(900) 000-00-00` подставляется при вводе;
- адрес становится обязательным, только если выбрана доставка курьером или по региону;
- на маленьком экране все поля выстраиваются в одну колонку.

## custom.css

Файл не дублирует Bootstrap, а только дополняет его:

- переменные проекта (`--shop-*`) и их значения для тёмной темы;
- фон hero-блока и градиент блока подписки;
- эффект наведения на карточки и увеличение изображения;
- круглые иконки преимуществ, квадратные кнопки-иконки в шапке;
- «липкие» фильтры каталога и блок «Ваш заказ» с отступом под шапку;
- фиксированная кнопка «Наверх» с плавным появлением;
- отключение анимаций при `prefers-reduced-motion`.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** из `vendor/bootstrap/` вместо CDN.
2. **Дополнительные страницы**: `contacts.html` с формой обратной связи и `404.html` для GitHub Pages.
3. **Корзина** в `offcanvas`: добавление из карточек и со страницы товара, изменение количества, удаление, итоговая сумма. Содержимое сохраняется в `localStorage` и не пропадает при переходе между страницами.
4. **Быстрый заказ** в `modal`: окно само узнаёт, из какой карточки его открыли, и подставляет товар. После отправки форма скрывается и показывается сообщение.
5. **Рабочие фильтры каталога**: категория, цена «от/до» с проверкой диапазона, «только в наличии», «новинки», «со скидкой», поиск по названию, сортировка, пагинация. Активные фильтры видны значками, каждый можно снять крестиком. Фильтры сохраняются в адресе (`catalog.html?category=audio`), поэтому работают ссылки из меню «Каталог» и поиск в шапке.
6. **Одна страница товара для всех товаров**: `product.html?id=N` заполняется из `js/data.js` (название, цена, скидка, наличие, характеристики, комплектация, похожие товары). Без JavaScript показывается первый товар, он размечен прямо в HTML.
7. **Сценарий заявки**: из корзины можно сразу перейти к заявке, товары подставятся в форму. Сумма пересчитывается при смене количества и способа доставки. После отправки показывается номер заявки, корзина очищается.
8. **Светлая и тёмная тема** через цветовые режимы Bootstrap 5.3 (`data-bs-theme`), выбор запоминается.
9. **Доступность**: ссылка «Перейти к содержимому», `aria-label` у кнопок-иконок, `aria-current` в меню, `aria-live` для сообщений, фокус на первом ошибочном поле.
10. **Собственные иллюстрации** товаров в SVG, логотип, `favicon`, превью Open Graph и `sitemap.xml`.

## Как проверить проект

1. Открыть сайт и уменьшить окно (или включить мобильный режим в DevTools). Меню сворачивается в кнопку, карточки перестраиваются, горизонтальной прокрутки нет.
2. На главной: карусель листается, вопросы в FAQ раскрываются, подписка без e-mail показывает ошибку.
3. Нажать «В корзину» у нескольких товаров: появится уведомление и счётчик на кнопке корзины. Открыть корзину, поменять количество.
4. Нажать «Заказать» в карточке: в модальном окне будет выбранный товар. Отправить пустую форму, увидеть ошибки, затем заполнить и отправить.
5. В каталоге выбрать категорию, задать цену, включить переключатели, ввести название. На телефоне фильтры открываются кнопкой «Фильтры». Внизу каталога листаются страницы.
6. Открыть товар (например, `product.html?id=7`, его нет в наличии) и переключить вкладки.
7. В корзине нажать «Оформить заявку»: товары подставятся в форму. Выбрать «Курьер», появится обязательное поле адреса, сумма изменится. Отправить форму.
8. Кнопкой с луной/солнцем в шапке переключить тему.

## Локальный запуск

```bash
git clone https://github.com/gothplug/kr2-bootstrap-shop.git
cd kr2-bootstrap-shop
python3 -m http.server 8000
```

Затем открыть http://localhost:8000. Можно открыть `index.html` и двойным щелчком: Bootstrap подключён локально, поэтому интернет не нужен.
